# codex-pets

Custom animated pets for Codex, with ready-made sprite sheets and previews.

| Pet | Preview | Download & setup |
| --- | --- | --- |
| **Hamblob** — a squishy triangular hamster | ![Hamblob](hamblob/previews/idle.gif) | [Hamblob README](hamblob/README.md) |

Each pet folder contains its artwork, previews, and setup instructions. Importing requires a compatible client with the Pets plugin; cloning this repository alone does not install a pet.
